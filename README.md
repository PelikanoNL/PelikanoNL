# 👋 ¡Hola! Soy Pelikano
### 🔍 Resolución de Problemas | Lógica Aplicada | Diagnóstico de Sistemas

> [!NOTE]
> **No soy programador de profesión ni me dedico a memorizar código.** Mi fuerte es otro: tengo una mente práctica orientada a la ingeniería inversa, desmontar problemas, aislar fallos y encontrar soluciones usando el sentido común y la lógica pura.

Si un software, una página web o un sistema tiene un fallo de comportamiento, mi cerebro mapea la lógica del problema al instante. No necesito conocer el lenguaje técnico desde el primer día; mi estrategia consiste en saber exactamente qué buscar en internet, hacer las preguntas precisas a bases de datos y herramientas de información, y cruzar los datos. Una vez que tengo las piezas correctas, utilizo la lógica para ensamblarlas y solucionar el problema por mí mismo de forma totalmente legal y eficiente.

## 🧠 Mi Forma de Trabajar

* **Mapeo Lógico** 🔍
  Capacidad para encontrar el "eslabón roto" en un flujo de código (como detectar una puerta en un juego que te lleva a la habitación equivocada).
* **Auditoría Cruzada** 🎯
  Aíslo trozos de código y realizo comprobaciones consultando diferentes fuentes independientes en internet. Si las respuestas coinciden, ejecuto la solución.
* **Investigación Autónoma** 🌐
  Sé cómo interrogar a los motores de búsqueda para dar con la solución exacta a un problema técnico sin quedarme bloqueado ante lo desconocido.
* **Enfoque Práctico** 🛡️
  Interés en la seguridad básica del día a día, como aislar de forma segura archivos dudosos (en entornos virtuales) para destripar su comportamiento y entender cómo funcionan por dentro.

## 💬 En resumen...

Si buscas a alguien que no se bloquee cuando algo falla, sino que aplique la **lógica, la investigación eficiente y la sensatez** para probar, encontrar el error y arreglar cosas, estás en el lugar correcto.
